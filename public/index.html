Chronology

  • Unit number when detected
  • Session number when detected
  • Lesson title keywords when detected

Known Limitation

If Lifeway uses repeated “Session 1” files across Unit 1 and Unit 2, this app needs the unit/title clues from the filename or folder path. The future best version will read the table-of-contents PDF and use it as the master lesson map.
